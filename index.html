01

基于 FPGA 的光纤接口输入 HDMI 输出盒

项目负责人 / FPGA 工程师 · 2024.02 - 2024.08

HDMI 输出盒接收前端设备的显示数据包，将数据包内容结合位置信息组织成 HDMI 输出视频流，用于测试前端控制器支持布局的完备性，并用于客户实时预览布局结果。

  • 设计产品原理图并审核 PCB 布局，主导硬件选型与架构设计。
  • 设计 ARM MCU 程序，移植 HDMI 芯片参考代码，配置 FPGA 被动加载。
  • 开发 FPGA 数据处理模块和光纤接收转发模块，采用 4K 视频数据 DDR 缓存策略，支持 4K 分辨率动态布局显示。
  • BRAM 占用率降低至 90% 以下；领导 3 人团队完成项目交付，资源利用率优化至 LUT 37%、BRAM 90%。
Xilinx Artix-7 XC7A75TGSV2011 HDMI 编解码芯片ARM MCUDDR 缓存

项目负责人 / FPGA 工程师 · 2023.03 - 2023.08

为解决原扫描卡逻辑兼容性不够、仅支持固定芯片级联规则和新驱动芯片支持不足的问题，优化芯片控制模块和显示数据 SDRAM 控制模块，提高兼容性。

  • 负责项目流程管控和 3 人团队工作管理。
  • 移植 FPGA 逻辑到新的 FPGA 硬件，重新设计 SDRAM 控制模块和 LED 驱动芯片控制时序模块。

  • 新扫描卡在 -40℃~75℃ 高低温环境下无网络误码，年出货量 100K+，应用于京港澳高速、华为 LED 会议一体机等高可靠场景。
